# 논문 좀비 · 대학원 준비 출석부

대학원 준비를 안 하면 좀비가 쫓아와요. 매일 하나라도 하면 출석이 되고 좀비에게서 도망칠 수 있어요.

## 출석
- **출석으로 인정되는 것**: 서재에서 논문 펼치기 · 논문 추가 · 분석/전문 해석 · Claude에게 논문 질문하기
- 처음엔 좀비와 6칸 거리(최대 10칸). 출석한 날 +2칸, 그냥 보낸 날 −3칸, 0칸이면 잡힘 → 다시 출석하면 3칸에서 재시작
- 좀비 추격은 메뉴의 "좀비 추격" 탭(또는 상단 🔥 배지)에서만 보여요. 메인 화면 맨 위는 오늘의 미션
- 출석 전에는 자정이 가까워질수록 좀비가 화면에서 슬금슬금 다가와요
- 출석 기록 달력, 연속 출석·최고 기록

## 논문 분석 (Claude)
PDF·TXT를 올리거나 본문을 붙여 넣으면:
- **요약**: 한 줄 요약, 핵심 bullet, 문제/방법/결과/기여/한계, 핵심 문장(원문+번역)
- **키워드**: 원어·한국어·논문 속 의미·중요도
- **전문 해석**: 약 4,500자씩 나눠 전부 한국어로 번역. 핵심 문장은 형광펜, 키워드는 보라색, 중요 수치·정의는 굵게. 원문 보기에서도 키워드·핵심 문장이 칠해져요
- **질문하기**: 논문 내용을 근거로 대화

## 실행
- 정적 웹앱이라 빌드가 필요 없어요. 저장소 루트를 https로 올리고(`/grad-zombie/`) 휴대폰에서 "홈 화면에 추가"
- 웹앱으로 쓸 때는 설정에서 Claude API 키를 넣어요 (키는 그 기기 localStorage에만 저장)
- `python3 grad-zombie/build-artifact.py 출력.html` → claude.ai 아티팩트용 단일 HTML. 아티팩트 안에서는 API 키 없이 내장 Claude를 쓰고, 기록은 계정별 비공개 저장소에 남아요
