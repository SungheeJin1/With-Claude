# 품사 탐험대 · 쉬운 영문법

초등학생 눈높이로 영어 8품사(명사·대명사·동사·형용사·부사·전치사·접속사·감탄사)를 설명하는 정적 웹사이트입니다.

- 품사별 탭, 목차, 예문(🔊 영어 읽기), 확인 퀴즈
- 어려운 문법은 단어 캐릭터가 등장하는 **웹툰**으로 설명 (예: `does`가 `has`의 s를 뺏어 가는 이야기)
- 동사는 **수 → 시제 → 태** 순서, 시제는 현재 → 현재진행 → 과거 → 과거진행 → 미래 → 현재완료 → 과거완료 → 가정법과거 → 가정법과거완료 순서

## 실행
빌드가 필요 없습니다. `index.html`을 브라우저로 열면 됩니다.

## 구조
- `js/data/0N-*.js` — 품사별 내용 (설명 HTML, 예문, 웹툰 패널, 퀴즈)
- `js/app.js` — 탭·웹툰·예문 렌더링
- `css/style.css` — 다크 글래스 디자인 및 웹툰 캐릭터(CSS로 그림)
- `fonts/` — Pretendard 글꼴 (SIL OFL 1.1)
